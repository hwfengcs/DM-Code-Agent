# v2.1.1 — 执行边界与审计可信度修复

这次发布落实 11 月 13、14、15 日审计中仍成立的执行、协议、统计和展示问题。
原始审计、会话、预测和历史评测不改写；没有新增真实模型或 SWE-bench 成绩。

- 四类执行工具默认 120 秒超时、每流 8 MiB 输出预算，保存独立原始输出；Windows Job Object
  回收父进程退出后的后代，Web 和 MCP 共用进程生命周期。绝对路径 unittest 文件可执行。
- Web 配置与实际参数一致；CLI 拒绝错误配置类型和原先被忽略的持久化参数组合。
- MCP 不自动重放丢失响应的工具调用，支持分页发现、有限通知队列及完整关闭；默认不经 Windows shell。
- OpenAI/Gemini 保留消息角色并传递生成参数；Claude 保留全部系统消息及版本头。
  GPT-5/o 系列保守省略采样参数；DeepSeek 默认不重试普通 HTTP 400。
- 摘要/诊断按 run 段读取；用户轮次与内部重试分开计数；完成否决有独立事件。
  修复粘性压缩重复统计、假失败记忆及旧消息重复吸收，原历史仍完整保留。
- 评测拒绝未知/空选择和错误类型，质量门禁核对原始结果；混合 usage 不漏算，
  不同重复次数的报告拒绝直接比较。经济性统计从原始结果重算。
- 用户 JSON 技能目录无需修改安装包；索引明确覆盖范围并隔离坏编码文件；SWE 准备容器唯一命名，
  拒绝损坏结构和有损补丁编码，刷新缓存前备份原件。
- 前端升级 Vitest 4.1.12；批量处理 SSE、限制缓存、修复非法路由和中断状态展示。

配置兼容说明：Web 不再读取 `config.json`，以界面默认值和请求值为准；CLI 原有配置仍可用。
摘要默认最后一段，旧段可通过 `--run-index` 或 Web 段选择器审查。
JSONL 离线读取仍严格拒绝损坏/未写完的记录；没有悄悄修复或丢弃日志。

安装包和 SHA-256 校验文件由 Release 工作流在完整验证与 Ubuntu/Windows 包外 smoke 通过后生成。
GitHub Release 是安装入口；PyPI 仅在仓库已有的发布开关及 Trusted Publisher 配置启用时发布。

详细处理范围与验证记录见 [审计跟进](audit-2026-11-15-followup.md)。
