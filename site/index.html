Built for inspection

A run you can work with.

01 / TRACE

Follow every step.

Keep plans, tool calls and results in an append-only session log. Context compaction preserves the original records.

02 / DIAGNOSE

Spot missing evidence.

Inspect failures, recovery and verification gaps. Compare two runs without reducing the story to a single success flag.

03 / SHARE

Send a readable report.

Export one standalone HTML file. Start with a safe summary; opt in to redacted content, review it locally, then share.

Start locally

Your first run.
Zero model calls.

Install the verified release wheel, then run the demo in a new directory. Python 3.10+ is required. The demo needs neither an API key nor pytest.

Full installation guide ↗
Terminal 
python -m pip install "https://github.com/hwfengcs/DM-Code-Agent/releases/download/v2.1.0/dm_code_agent-2.1.0-py3-none-any.whl"
dm-agent-demo --output demo-run
dm-agent-trace export demo-run/sessions/verified.jsonl --output repair.html --include-content

Open repair.html in your browser. The demo writes only inside its new directory; existing contents are never overwritten.

Know the boundaries.

Local-first does not mean sandboxed. Live tasks can modify files and run commands with your permissions. Review shared reports: automatic redaction cannot identify every secret. Historical benchmark results and their sample limits are documented in the repository.
